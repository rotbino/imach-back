# local-data/

این پوشه شامل داده‌های خام استخراج‌شده از API برکوداپ (barcodeapp.ir) است.

## محتویات

| فایل | حجم | توضیح |
|------|-----|-------|
| `categories.json` | 40 KB | ۲۷۲ دسته با parent_id و تعداد محصولات |
| `brands.json` | 92 KB | ۱,۱۴۴ برند از API با تعداد محصولات |
| `products-merged.json` | 91 MB | **تمام ۴۲,۰۲۷ محصول با برند استخراج‌شده** |
| `products-merged.json.gz` | 7.8 MB | نسخه فشرده (برای انتقال سریع‌تر) |
| `fetch-all-summary.json` | 1 KB | متادیتای دانلود (۴۲۱ صفحه، ۰ خطا) |
| `fetch-all-log.json` | 2 KB | لاگ فرآیند دانلود |
| `manifest.json` | 2 KB | آمار کامل و لیست برندهای کشف‌شده |

## آمار نهایی

- **کل محصولات:** ۴۲,۰۲۷
- **با برند (مستقیم از API):** ۱۳,۳۴۷ (۳۱.۸٪)
- **با برند (استخراج از نام):** ۱۶,۳۶۴ (۳۸.۹٪)
- **مجموع با برند:** ۲۹,۷۱۱ (۷۰.۷٪)
- **بدون برند:** ۱۲,۳۱۶ (۲۹.۳٪)
- **با دسته:** ۱۹,۰۷۳ (۴۵.۴٪)

## برندهای کشف‌شده (۱۱۴ مورد)

علاوه بر ۱,۱۴۴ برند موجود در API، ۱۱۴ برند جدید از نام محصولات استخراج شد:

- تنباکو: مزایا، بنگ بنگ، ادالیا
- شوینده: هداندشولدرز، سان سیلک، شوارتسکف
- شکلات: میلکا، نستله، کیت کت، ام اند ام، ریتر اسپرت، مارس، اسنیکرز، اورئو، لینت، کیندر، آلپن گلد، نوتلا
- قهوه: نسکافه، استارباکس، نسپرسو
- لوازم آرایشی: لورآل، داو، رکسونا، نیوآ، گارنیه، پنتن
- بهداشت دهان: سنسوداین، لیسترین، توتال کر، تیک تاک
-其他: ژیلت، دتول، پرینگلز، کنور، جانسون، هاینز، دوراسل، امریکن گاردن، پالمولیو
- لبنیات و غذایی: میهن، کاله، پمینا، معینی پور، دادلان، نظری
- نوشیدنی: بالتیکا، موهیتو، پژآیس

## روش استخراج برند

برای محصولات بدون برند (`item.brand` = null):

1. **اول کلمات چندکلمه‌ای** تطبیق داده می‌شن (مثل "سان سیلک"، "امریکن گاردن") - اولویت با بلندترین تطابق
2. **سپس کلمات تکی** با token-boundary matching (مثل "کاله"، "نستله")
3. اگر هیچ تطبیقی پیدا نشه، محصول بدون برند می‌مونه (در ایمپورت به "نامشخص" اختصاص می‌یابد)

## نحوه ایمپورت به MongoDB

اسکریپت ایمپورت در `scripts/import-from-merged.js` از روی `products-merged.json` می‌خونه.
