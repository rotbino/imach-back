# local-data/

این پوشه شامل داده‌های خام استخراج‌شده از API برکوداپ (barcodeapp.ir) است.

## محتویات

- `product-{N}.json` — خروجی خام API برای صفحه N (هر صفحه ۲۰ آیتم)
- `manifest.json` — خلاصه وضعیت فعلی و آمار داده‌ها
- `failed.json` — (اگر وجود داشت) لیست صفحاتی که دانلودشان ناموفق بوده

## وضعیت فعلی

- تعداد کل صفحات در API: ۲۱۰۲
- تعداد کل محصولات در API: ۴۲۰۲۷
- صفحات کش‌شده: ۳۹۶ (۱۸.۸٪)
- صفحات باقی‌مانده: ۱۷۰۶

## نحوه دانلود صفحات بیشتر

اسکریپت دانلود در `scripts/fetch-all.js` پروژه `my-project` قرار دارد.

```bash
TOKEN="<bearer_token>" node /home/z/my-project/scripts/fetch-all.js
```

اسکریپت خودکار صفحاتی که قبلاً دانلود شده‌اند را تشخیص می‌دهد و فقط صفحات جدید را می‌گیرد.

## نحوه ایمپورت به MongoDB

پس از تکمیل دانلود همه صفحات، اسکریپت ایمپورت در `scripts/import-from-cache.js` اجرا می‌شود.

## نکته

این پوشه در `.gitignore` است و در گیت نمی‌رود زیرا حجم زیادی (نزدیک به ۱۰۰ مگابایت بعد از تکمیل) دارد.
برای تولید مجدد، فقط به یک توکن معتبر barcodeapp.ir نیاز است.
